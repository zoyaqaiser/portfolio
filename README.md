Put it on GitHub (free hosting via GitHub Pages)
Go to your repo on github.com.
Click "uploading an existing file" (or Add file → Upload files).
Drag in index.html and this README.md, then scroll down and click Commit changes.
Go to Settings → Pages (left sidebar).
Under "Build and deployment," set Source to Deploy from a branch, branch main, folder / (root), then Save.
Wait about a minute — your site will be live at: https://<your-username>.github.io/<repo-name>/
Updating the site
Edit index.html directly in GitHub (pencil/edit icon on the file) and commit the change — no local setup required. Changes usually go live within a minute or two.
