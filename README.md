## ⚙️ Featured Project: Lead-Intake Automation Simulator

One of the main features of this portfolio is an interactive lead-intake automation simulator.

It demonstrates how incoming customer enquiries can be processed through an automated workflow.

### Workflow Process

1. **Trigger:** Receive an enquiry through a form, email, or WhatsApp.
2. **Get Data:** Extract and organize contact information, budget, and message details.
3. **AI Step:** Classify the enquiry, analyze sentiment, and calculate a lead score.
4. **Check & Route:** Identify spam, urgent enquiries, potential customers, and support requests.
5. **Deliver:** Generate a response, determine the next action, and log the result.

### Key Features

- Lead categorization (Sales, Support, Partnership, Spam, General).
- Automated lead scoring.
- Email, phone number, and budget extraction.
- Urgency and sentiment detection.
- Spam filtering.
- Automatic reply drafting.
- Workflow execution history.
- CSV export and JSON payload preview.
- Customizable reply tone.

**Note:** The workflow is a front-end simulation using JavaScript-based rules. It demonstrates automation logic rather than connecting to live n8n, Zapier, or external AI services.
